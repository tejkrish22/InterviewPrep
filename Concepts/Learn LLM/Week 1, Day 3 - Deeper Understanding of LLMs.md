1. LLMs come in 3 flavors
    1. Base Model 
        1. LLM that takes sequence of input and predict what comes next.
        2. Basically Predictive text
        3. Better for fine-tuning to learn a new skill.
    2. Chat/Instruct Model
        4. ChatGPT, so basically its like trying to complete the chat.
        5. Better for interactive use cases and creative content generation (opinion)?
    3. Reasoning/Thinking model
        6. Before replying, the model is made to think and reason before replying.
        7. Reasoning has limit and this is called as Reasoning Budget. 
        8. `To think more deeper - Budget forcing , the word wait is added so as to make model think inlines - Wait! Is this correct?`
        9. Better for problem solving.

3. Advantages of Frontier LLMs
    10. Synthesizing Information - Answering a question with a structured, well researched answer and often including a summary.
    11. Fleshing out a skeleton - From a couple of notes, building out a well crafted email, or a blog post and iterating on it with you until perfect.
    12. Coding - The ability to write and debug code is remarkable, far overtaken Stack Overflow as the resource for engineers.
4. Disadvantages of Frontier LLMs
    13. Specialized Domains - Most are not PhD level, but closing in.
    14. Recent Events - Limited knowledge beyond training cut-off data; code often legacy APIs/models
    15. Can confidently make mistakes - Some curious blindspots can jump to conclusions when coding. Hallucination happens with too much conviction 😂.
5. For Coding - LLMs work the best under supervision.
6. Good questions to ask an LLM
    16. `How many times does 'a' appear in this question`?
    17. `How many words are there in your answer to this sentence` ?
    18. Analytical, Philosophical, Self-Feedback, Self-Question the answer.
