# What is Cloud Computing?

## Definition

> Cloud Computing is the **on-demand delivery** of compute power, database storage, applications and other IT resources.

1. Use services from the provider with `pay-as-you-go` pricing.
2. Provision `exactly the right type and size of computing resources` you need.
3. `Instant access` of resources.

## Deployment models of the cloud

### Private Cloud

1. Cloud services used by a single organization, not exposed to public.
2. Complete control.
3. Security for sensitive applications.
4. Meet specific business needs.
5. Ex: Rackspace

### Public Cloud

1. Cloud resources are owned and operated by a third-party cloud service provider delivered over the internet.
2. Six Advantages of cloud computing.
3. Ex: Azure, Google Cloud, AWS

### Hybrid Cloud

1. Keep some servers on premises and extend some capabilities to the cloud.
2. Control over sensitive assets in your private infrastructure.
3. Flexibility and cost-effectiveness of the cloud.

## The Five Characteristics of Cloud Computing

**On-Demand Self Service**: Users can provision resources and use them without human interaction from the service provider.

**Broad network access**: Resources available over the network, and can be accessed by diverse client platforms

**Multi-tenancy and Resource Pooling**: Multiple customers can share the same infrastructure and applications with security and privacy

**Rapid Elasticy and scalability**: Automatically and quicky acquire and dispsose resources when needed

**Measured service**: Usage is measured, users pay correctly for what they used.

## Six Advantages of Cloud Computing

1. Trade capital expense (CAPEX) for operational expense (OPEX).
2. Benefit from massive economies of scale.
3. Stop guessing capacity.
4. Increase speed and agility.
5. Stop spending money running and maintaining data centers.
6. Go global in minutes.

## Problems solved by the cloud

1. Flexibility
2. Cost-Effectiveneses
3. Scalability
4. Elasticity
5. High-Availability and Fault Tolerance
6. Agility
