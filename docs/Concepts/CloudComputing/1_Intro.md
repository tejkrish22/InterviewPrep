# Intro to Cloud Computing

## How Websites work

1. Consider opening `google.com` in your browser.
2. Here the browser is the client and `google.com` is a server.
3. Both Client and server will have an IP Address associated with it.
4. These are connected via network.
5. So the client will send a request to the server (located by IP Address).
6. And the server responds back to the requestor IP.

## What is server composed of?

1. Compute: CPU + Memory: RAM -> Brain
2. Storage: Data
3. Database: Store Data in structured way
4. Network: Routers, Switch, DNS Server

## IT Terminology

1. Network: Cables, routers, and servers connected with each other
2. Router: A networking device that forwards data packets between computer networks. They know where to send your packets on the internet.
3. Switch: Takes a packet and send it to the correct server/client on the network.

## Traditional Setup

1. As we establish a company, it starts with a single server.
2. Then as the company scales up, we would move to data center.
3. But the problems with data center are
    1. Pay for the rent of the data center
    2. Pay for the power supply, cooling, maintainance.
    3. Adding and replacing hardware takes time
    4. Scaling is limited
    5. Hire 24/7 to monitor the infra.
    6. How to delal with disasters?

## Cloud Computing

1. So to avoid above issues, `Cloud Computing` can be chosen.
