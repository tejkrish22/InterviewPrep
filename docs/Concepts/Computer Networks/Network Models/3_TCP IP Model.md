## Intro

1. TCP - Transmission Control Protocol
2. IP - Internet Protocol
3. TCP/IP model is
	1. practical
	2. protocol-based
	3. used for real communication
	4. closer to how networks actually work

## Why TCP / IP name?

1. Transport layer can use TCP or UDP.
2. TCP and IP are deeply associated with early internet communication
3. TCP / IP does not mean only TCP, IP; rather it is a family of protocols - TCP / IP suite.

## TCP / IP Protocol Stack

1. **Application Layer**
	1. HTTP, DNS, FTP
	2. application message
2. Transport Layer
	1. TCP, UDP
	2. Segment, Datagram
3. Internet Layer
	1. IP, ICMP, ARP
	2. Packet
4. Data Link
	1. Ethernet
	2. Frame
5. Physical 
	1. Actual Transmission
	2. bits / signals

## TCP / IP - OSI Mapping

1. Application - Application, Presentation, Session
2. Transport - Transport
3. Internet - Network
4. Link - Data Link, Physical
