
## What is Hybrid Routing ?

1. Hybrid Routing is a bridge between simple and advanced routing approaches.
2. In networking, Hybrid Routing attempts to combine
	1. The simplicity of Distance Vector Routing.
	2. The efficiency and faster convergence characteristics of Link State Routing.
## EIGRP

1. The most commonly discussed example of Hybrid Routing is **EIGRP (Enhanced Interior Gateway Routing Protocol)**
2. EIGRP is often described as a Hybrid Routing Protocol because it combines characteristics associated with both Distance Vector and Link State approaches.
3. It can also be described as an advanced Distance Vector Protocol because it builds upon traditional Distance Vector ideas while introducing additional optimisations.
## How EIGRP Fits Between RIP and OSPF

A useful way to understand EIGRP is to compare it with RIP and OSPF.

- **RIP:** Simple but limited.
- **OSPF:** Powerful and scalable but more complex.
- **EIGRP:** Sits between these two approaches.

EIGRP attempts to provide better performance than traditional Distance Vector protocols while avoiding some of the complexity associated with full Link State protocols.
