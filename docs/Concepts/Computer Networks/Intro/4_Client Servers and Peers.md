## Client and Server

> **Client**: A device or program that requests a service
> - browser requesting a home page
> - mobile app calling an API
> - postman calling a backend

> **Server**: A device or program that provides a service
> - web server sending HTML
> - API server returning JSON

Client asks, Server responds

## Client Server Architecture

1. Responsibilities are shared
2. Easier Control and management
3. Centralised data and logic
4. The same machine can be a client in one flow and a server in another.

## Peer-to-Peer Architecture

 ![[peer.png|center|287]]

1. Peers can both request and provide
2. Machines at the edge can participate in serving
3. More Distributed - No Central server
4. More resilient and scalable

## Hosts, Nodes and Links

> Host: End device that sends or receives data. Ex: Laptop, Mobile and server

> Node: Any device in the network. Ex: Router, Switch, Firewall

> Link: Communication path connecting nodes. Ex: Wifi, Ethernet, Fiber
