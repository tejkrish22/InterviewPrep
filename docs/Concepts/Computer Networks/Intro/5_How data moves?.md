## How?

1. You do not send one giant block of data.
2. Networks move data in small units called Packets.

## Why data moves in packets?

1. Easier to share the network
2. Easier to forward
3. Easier to recover from errors
4. Easier to manage long communication

## Basic Network Terms

> **Bandwidth:** Maximum theoretical capacity of a link. Usually measured in bps.

> **Throughput:** Actual rate at which data is successfully transmitted.

> **Latency:** The data time taken for a packet to travel from sender to receiver.

> **GoodPut:** The actual useful data delivered from source to destination. GoodPut excludes protocol overhead, retransmitted data, extra control data.
