## Internet - Network of Networks

1. The internet is a global system of interconnected networks.
2. These networks communicate through the *TCP/IP protocol suite*.
3. The internet is not owned by one company
4. It is built by networks owned by
	1. Internet Service Providers
	2. Cloud Providers
	3. Telecom Providers
	4. Universities
	5. Organisations

## Backbone Network

> A very high-capacity core network that carries large volumes of traffic over long-distances.

1. It uses
	1. Fiber optic links
	2. High Speed routers
	3. Undersea cables
2. Simple Analogy - Backbone networks are highways of internet.
3. Purpose - Move huge internet traffic between regions, countries, ISPs and Data Centres.
