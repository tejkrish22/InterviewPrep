> Made of pairs of insulated copper wires twisted together.

## Why twist them?

Twisting helps both wires experiences similar noise, so the receiver can cancel it better.

1. Reduces Electro-Magnetic Inference.
2. Reduces crosstalk.
3. Helps noise cancellation
4. Improves signal quality
5. Reduces transmission errors

## Used In

1. Ethernet LANS
2. Homes 
3. Offices

## Types

### Unshielded Twisted Pair

1. No metallic shielding
2. Cheaper
3. Easy installation
4. No grounding needed
5. Lighter and thinner
6. Normal LANS
### Shielded Twisted Pair

1. Has metallic shielding
2. Costly
3. Harder installation
4. Proper grounding needed
5. Heavier and bulkier
6. Useful in noisy environments.
