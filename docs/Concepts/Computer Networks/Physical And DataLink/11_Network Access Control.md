
> A security framework that controls which users and devices can access a network.

## What NAC layer does

1. Checks identity
2. Authentication status
3. Device Compliance
4. Security Posture
5. Policy rules

## Purpose

1. Allow only trusted devices
2. Block unauthorised access
3. Check antivirus/OS Updates
4. Apply different access levels

## Types of NAC

1. Pre-Admission NAC
	1. Checks device before allowing network access
	2. Verifies compliance first
	3. Then grants access
2. Post-Admission NAC
	1. Monitors device after access is granted
	2. Can restrict access later
	3. Useful if device becomes NC
