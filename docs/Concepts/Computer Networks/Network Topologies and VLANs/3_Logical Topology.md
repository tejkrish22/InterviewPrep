> Logical topology describes how data actually flows, regardless of physical shape.

## One Switch, Many LANs

1. Network behaviour is not only decided by cable layout, but also decided by
	1.  Switching Behaviour
	2. MAC Learning
	3. VLAN Membership
	4. Broadcast Domains
	5. Routing Boundaries
	6. Policies
2. If a switch has 10 ports, we can assign 1-4 to VLAN 01 and 5-10 to VLAN 02.
