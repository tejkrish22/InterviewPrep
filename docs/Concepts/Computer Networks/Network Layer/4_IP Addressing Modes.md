
Defines how an IP packet is delivered to 
1. One device
2. All devices
3.  Group pf Devices
4. Nearest Among many.

| Type       | Description                                       | Example                                      |
| ---------- | ------------------------------------------------- | -------------------------------------------- |
| Uni-cast   | one sender -> one receiver                        | An SSH client connecting to a remote machine |
| Broadcast  | one sender -> all hosts in local broadcast domain | DHCP Discovery Messages                      |
| Multi-cast | one sender -> interested group                    | Streaming Services                           |
| Any-cast   | one sender -> nearest / best server               | Content Delivery Networks (CDNs)             |
