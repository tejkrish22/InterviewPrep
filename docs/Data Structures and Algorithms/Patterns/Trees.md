# Trees

## Recognition Cues
- Hierarchical structures, parent-child relationships, subtree recursion.
- Traversals: Inorder (L-Root-R), Preorder (Root-L-R), Postorder (L-R-Root), Level order (BFS).

## Common Pitfalls
- Null check base case: check `root == nullptr` before accessing `root->left` or `root->right`.
