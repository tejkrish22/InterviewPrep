# Stack

## Recognition Cues
- LIFO, matching brackets, expression evaluation, Monotonic Stack (Next Greater Element, Daily Temperatures).
- Push elements onto stack; pop when current element breaks monotonic ordering.

## Common Pitfalls
- Store **indices** on stack instead of values when distance/width calculations are needed.
